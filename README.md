# Data Structures and Algorithms (DSA)

## Assignment – Submission 1

### Programming Language
Java

### Description
This repository contains the Java implementations of selected data structures and their operations as part of the Data Structures and Algorithms assignment.

The assignment focuses on understanding and implementing stacks and queues using different approaches.

### Implemented Programs

The following programs are included in this submission:

1. **QueueStack – Push Friendly**
   - Implements a Stack using two Queues.
   - Optimizes the Push operation.

2. **QueueStack – Pop Friendly**
   - Implements a Stack using two Queues.
   - Optimizes the Pop operation.

3. **Unbounded Array Stack**
   - Implements a Stack using a dynamically resizable array.
   - Automatically increases and decreases the array capacity based on the number of elements.

4. **StackQueue – Enqueue Friendly**
   - Implements a Queue using two Stacks.
   - Optimizes the Enqueue operation.

### How to Run the Programs

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure that the Java Development Kit (JDK) and Java Extension Pack are installed.
4. Open the required `.java` file inside the `src` folder.
5. Click the **Run** option above the `main()` method to execute the program.
